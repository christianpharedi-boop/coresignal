# M1 — Inner-core signal to LOD out-of-sample test

M1 is registered as a **specified but not executable** experiment. It must not search for an inner-core series after inspecting LOD correlations, and it must not execute until the observable, source, feature construction, uncertainty treatment, temporal coverage, and matched rolling M0 control are frozen.

The original M0 test interval remains immutable, but an inner-core predictor that ends before 2026 cannot be compared against that full interval. If the selected source ends in 2023, M1 must use a named overlap interval and a newly generated matched M0 rolling control on exactly that interval. It must not be described as outperforming the original 2016–2026 M0 result.

The current candidate is an event-level PKIKP waveform-change score. This is deliberately treated as a seismic change observable, not as a directly observed scalar inner-core rotation rate. M1 will remain blocked until a specific event/station dataset and feature recipe are documented and hashed.

No inner-core data, predictor, model result, or scientific conclusion is included by this scaffold.
