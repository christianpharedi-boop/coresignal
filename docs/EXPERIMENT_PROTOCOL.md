# Experiment Protocol

No final scientific claim may be made from an ad hoc notebook run.

Each experiment must have:

1. A unique experiment identifier.
2. A versioned configuration.
3. Declared data inputs.
4. Declared target and predictors.
5. Declared temporal split.
6. Declared primary metric.
7. Declared acceptance threshold.
8. Recorded code and data hashes.
9. Generated result artifacts.
10. A machine-readable manifest.

The final test period must remain locked until model selection is complete.
