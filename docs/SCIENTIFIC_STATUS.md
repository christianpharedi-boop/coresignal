# Scientific Status

CoreSignal distinguishes repository progress from scientific evidence.

- SPECIFIED: protocol defined.
- INGESTED: source data validated.
- EXECUTED: analysis ran.
- REPRODUCED: clean execution reproduced outputs.
- SUPPORTED: registered acceptance criteria passed.
- NOT_SUPPORTED: registered acceptance criteria failed.
- INVALIDATED: analysis cannot be interpreted because of a methodological or data-quality failure.

These labels are evidence states, not marketing claims.
