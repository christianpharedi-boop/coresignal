# Changelog

## 0.2.0 - 2026-08-17

CoreSignal v0.2 introduces the scientific specification and experiment-governance layer.

### Added

- Falsifiable research hypotheses and predictions.
- Formal variable and unit definitions.
- Data-source registry and provenance requirements.
- Inner-core state representation.
- LOD and geomagnetic ingestion contracts.
- Null, lagged, competing, and coupled models.
- Temporal out-of-sample validation protocol.
- Uncertainty and robustness requirements.
- Explicit scientific acceptance and rejection criteria.
- Experiment manifest schema.
- Scientific audit-trail requirements.
- Planned result figures and tables.
- Reproducibility gates.

### Not claimed

v0.2 does not claim a scientific result. It defines how a result will be tested.
